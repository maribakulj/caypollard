# The node vocabulary as a vision model can see it.
#
# Iconclass supplies the discipline's names, and the measurement says a model
# cannot ground them: given "fable", "domesticated animal" or "mandrake" as its
# only choices, a 3B vision-language model answers "mandrake" five times for a
# photograph of a dress. Given ordinary nouns it answers "dress". The catalogue
# term is the right name for a finding and the wrong name for a prompt, so the
# two are separated: a picture is transcribed into words a model can see, and
# the mapping to Iconclass is a later step performed on the transcription.
#
# The list is closed, and chosen for what pictures in these corpora contain
