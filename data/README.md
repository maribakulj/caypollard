# Data directory

Do not commit full third-party image collections here unless redistribution rights explicitly permit it.

## Layout

- `manifests/`: source identifiers, metadata, labels, rights, checksums, split assignments;
- `samples/`: tiny fixtures or legally redistributable examples for tests and notebook smoke runs.

## Canonical manifest

The initial manifest format is JSON Lines. See `manifests/example.jsonl`.

Full-data acquisition scripts will be added only after source terms and APIs are documented.
